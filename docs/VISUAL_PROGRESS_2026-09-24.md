# Наглядность планов и аудитов

Исходная экспертная оценка: цель и следующий шаг доступны, но разнесены между
большими блоками; статусы планов выводились по-английски; исправления аудитов
приходилось искать в хронологии. Это осмотр, не исследование случайных пользователей.

Добавлены первая сводка «Картина разработки», интерактивное распределение планов,
отдельный реестр 10 выбранных проблем с доказательствами, история по датам UTC.
Пять исправлены в ограниченном проверенном объёме, две частичны, три открыты.
Это вручную сопоставленная выборка прошлых аудитов, не автоматическое обнаружение
и не знаменатель всех дефектов. Новые наблюдения той же проблемы заменяют только
текущую проекцию, исторические события не удаляются. Нет источника/события проверки
— UI показывает неизвестный статус. Планы без знакомого статуса не исчезают.

Цель, ограничения, источник, критерии и полные тексты остаются доступны. Изменение
не подключает ChatGPT и не устанавливает модели. График показывает записи журнала,
не выполненный функционал: служебная активность также считается. Отсутствующие даты
отмечаются отдельно; фильтр означает последние даты с записями, не календарные дни.
Полосы открывают записи; статусы имеют текстовые подписи; есть reduced-motion.
Показатели подключения/защиты спрятаны в раскрываемые подробности; ограничения
сбора видны в основной сводке. Полная карта планов — STATE_AUDIT_2026-09-24.md.

GitHub-first 2026-09-24: запросы `github chartist chartist SVG charts license`,
`github charts css accessible charts`; открыты chartist-js/chartist и
ChartsCSS/charts.css (README main, SHA не закреплён; только исследование).
Chartist предлагает SVG runtime; Charts.css — семантическую HTML/CSS визуализацию,
MIT. Для двух категориальных распределений и полос дат используем существующий
DOM renderer и native CSS: фильтрация и source gating остаются кодом FIX;
не добавляем runtime/CDN и не копируем upstream код без pinned provenance.
Перенесена общая идея доступных HTML-графиков, не библиотека Charts.css.
Преимущество: offline snapshot сохраняет интерактивность; ускорение разработки
и пользовательское понимание сравнительным исследованием не измерены.

# Сохранённые GitHub-снимки

В «Открыть GitHub» загрузите публичный репозиторий и нажмите «Сохранить снимок
в браузере». При следующем открытии выберите репозиторий и дату в списке.
Снимок открывается без запроса к GitHub и явно помечается как сохранённый.
Чтобы получить новые сведения, используйте «Получить сведения» ещё раз.
Передача в AI-чат и JSON export используют именно открытый снимок.

Это кэш текущего browser origin: другой адрес, порт, браузер или устройство
не обязаны видеть те же данные. В режиме file:// хранение зависит от браузера;
ошибки показываются. Очистка данных сайта удаляет кэш. JSON нужен для резервной
копии. Кэш не является каноническим журналом, источником истины или подпиской.
Автоматического импорта в проект нет; текущий project_id не изменяется.

Ограничения: 20 снимков, 500 тыс. символов на снимок, 2 млн суммарно. Превышение
и quota errors не удаляют прежние записи. «Убрать этот снимок из кэша» удаляет
только выбранную запись; открытый пакет остаётся в памяти и может быть сохранён
снова. Повтор идентичного снимка не создаёт дубль. Конфликт той же repo/date
отвергается. Повреждённые записи пропускаются с предупреждением. Отдельные ключи
сохраняют параллельные записи разных снимков; лимит размера не является глобальной
транзакцией между вкладками. Снимки не имеют криптографической аутентификации.

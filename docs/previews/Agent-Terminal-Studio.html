С чего начать

Посмотрите следующий шаг в «Обзоре», откройте «Задачи» или найдите сохранённый текст в «Сообщениях». Для нового чата скопируйте полный контекст.

Если данных нет, откройте снимок с данными или подключите выбранный проект через локальный запуск FIX. Сообщения добавляются импортом доступного файла переписки. Эта панель только показывает сохранённое: она не подключает аккаунт и не запускает исполнителей.

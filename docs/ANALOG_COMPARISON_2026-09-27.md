конкурентов и не визуальное тестирование. Сравниваются отдельные функции: наш
терминал прежде всего хранит доказуемую историю, а не заменяет IDE/агентный сервер.

Лицензии: Langfuse MIT вне ee-путей (они имеют отдельные условия); Agent Chat UI MIT;
Basic Memory AGPL-3.0; Octokit MIT. Langfuse/Agent Chat UI/Basic Memory не установлены,

страниц не включена: лишние запросы расходуют публичную квоту, API не атомарен.
Не обещаем «все сведения», токены/стоимость/активность не вычисляем без источника.

Открытые пробелы: authenticated private repos, долговечный импорт repo evidence,
реальный transport к моделям, live chat ingestion, native browser visual QA, A6.
Это границы продукта, не устранённые установкой библиотеки.

## Фактическое внедрение и проверка

Добавлен раскрываемый обозреватель всех запусков: комбинированный поиск по
run/task/session/model, статус, модель, порции по 20, длительность только из двух
валидных временных меток, stdout/stderr и event ID. Работа с фильтрами защищена
от фоновой перерисовки, переходы в другие разделы сохраняются.
GitHub receipts содержат has_more, http_status, rate_remaining, rate_reset и
retry_after; UI предупреждает о наличии следующих страниц и показывает сведения
об ошибке. Это не автоматическая пагинация и не целостный GitHub snapshot.

Проверено локально: run explorer Node tests PASS, GitHub receipt tests PASS,
прежние connection tests PASS, DOM regression всех 11 разделов PASS, 5 Python
тестов dashboard PASS. Новый API-контракт испытан на синтетических HTTP-ответах;
live rate limit намеренно не исчерпывался. Пользовательское время поиска,
производительность и премиальность дизайна не измерены. Browser visual QA
остаётся открытой. Новых платных сервисов и модельных вызовов не подключено.

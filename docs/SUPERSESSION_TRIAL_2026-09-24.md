# Передача заменённого решения

Обнаружен дефект history_review.review: active_decisions содержал только новые
решения, superseded_decision_ids — идентификаторы старых. Тексты и источники
старых решений терялись при передаче только результата review. Прежний тест
проверял неизменность INPUT и потому не обнаруживал потерю OUTPUT.

Новый тест сериализует результат и проверяет сохранение обеих записей, причины,
источников и evidence-классов. До исправления: KeyError decisions; после — PASS.
Результат review теперь содержит полный decisions вместе с active/superseded.
Это обратно совместимое добавление поля; новая зависимость не нужна.

Документированный пример: замена удаления lock по возрасту на portalocker OS lock.
Вход SUPERSESSION_TRIAL_INPUT.json — явная подготовленная реконструкция по двум
аудиторским документам, не исходные сообщения и не автоматическое извлечение.
Воспроизведение: python history_review.py docs/SUPERSESSION_TRIAL_INPUT.json.
Отдельный субагент получил только полученный JSON без истории диалога. Правильно
назвал old/new, причину, обе ссылки, ограничение смешанного протокола; не повысил
reported до verified. Координатор сопоставил ответ с эталоном. Это не внешний A6.

Полный локальный прогон после Python-исправления: 215 тестов PASS, 10,231 с.
Восемь review tests PASS. Последующее изменение только текста download notice
не выдаётся за отдельный браузерный тест.

Download: при реальном нажатии ожидание browser download event истекло через
12 секунд. Получение файла/байтов не подтверждено; причина неизвестна. Полученные
console ошибки расширения не доказывают причину. Панель теперь предлагает
проверить загрузки и использовать проверенный ручной copy fallback при отсутствии
файла. Браузерные ограничения не обходились.

Текущий coverage conflict уточнён append-only patch: авторизованные частичные
наблюдения существуют, но полного экспорта нет. Исторические записи сохранены.
Дальнейший приоритет — аварийная первоначальная запись и причинная диагностика
потери хвоста. Автосбор, автоматический limit handoff и full A6 остаются открыты.

# Аудит собственного проекта и использование терминала в текущем чате

Дата наблюдения: 2026-09-24 UTC. Проект: `project-history-agent`, репозиторий
`loftfull/FIX`, ветка `codex/history-mcp-foundation`, draft PR #5.
Локальная рабочая копия: `/workspace/scratch/c911ac0d5396/repos/FIX`.
Это рабочая среда текущей сессии, не обнаруженная папка на компьютере пользователя.

## Вывод

Архитектура сохраняет связь с главной задачей: доказательная история и передача
контекста. Полная реализация исходного замысла НЕ подтверждена. Обнаружено реальное
отставание собственной памяти: новые модули были описаны событиями, но структурные
таблицы планов, версий и расположений остановились на v0.7. Это исправляется новыми
записями, без переписывания прежних. Отсутствие записанных противоречий не доказывало
отсутствие проблем. Слово «Франкенштейн» не технический критерий: связность ядра есть,
но рост UI/supervisor до завершения исторической приёмки создаёт риск отвлечения.

## Покрытие источников

- Доступны весь локальный Git-журнал, исходники, текущий журнал из 102 записей до
  этого аудита, планы и протоколы испытаний. Их целостность не доказывает полноту
  исходных разговоров. Исторические local SHA отличаются от опубликованных SHA
  из-за метаданных коммитов; не смешиваем их.
- `chat/current/USER_MESSAGES.md` — четыре ранних выбранных запроса, не весь чат.
  Новый `USER_REQUEST_2026-09-24.md` сохраняет текущий запрос дословно. Его дата —
  наблюдение в этой сессии, не восстановленный server timestamp сообщения.
- Видимая переписка задаёт исходную цель и последующие требования. Полного экспорта
  текущего чата с оригинальными ID, датами, всеми ответами и вложениями нет.
  `chat-current-project-history-agent` — внутренний ID памяти, не server chat ID.
- Поиск личного контекста 24 сентября вернул ошибку поиска разговоров и прежние
  производные файлы. Он не открыл оригиналы чатов и не расширил полноту корпуса.
- Реальный архив 18 сообщений / 94 726 символов проверен ранее. Это другой чат
  поиска инструментов, НЕ история реализации FIX и НЕ INSTA.
- Для INSTA ранее доступны 139 GitHub issue comments и два документа; оригинальные
  чаты недоступны. Этого недостаточно для полной причинной истории тупиков.
- Реакции прежних моделей, неизвестные model/session IDs и пользовательские папки
  не восстанавливаются по догадке. Независимый аудитор этого цикла — отдельный
  агент текущей среды; это не доказательство прохождения внешнего A6 другой моделью.

## Приоритет и ответвления

Основная цепочка: v0.3 → v0.4 → v0.5 → v0.6 → v0.7 → MCP/import/watch.
Terminal/focus/visual/runner — поддерживающая линия, запрошенная пользователем;
vault — ответ на дефект сохранности. Это компоненты одного проекта, не доказанные
самостоятельные Git-forks. Отдельные InstaVault и TERMINAL не объединяются с FIX.

Ни одна ветвь не объявляется подтверждённым тупиком только из-за числа исправлений.
Два естественных эпизода потери хвоста и продолжающаяся диагностика — кандидат на
проблемный путь с неизвестной причиной. Бесконечно добавлять новые backup-слои вместо
разбора источников и приёмки нельзя. Сначала актуальный паспорт и покрытие истории,
затем причинная проверка сохранности/A6; дополнительные provider/UI расширения вторичны.

## Что означает «используется в этом чате»

В канонической памяти регистрируется задача `current-chat-audit-2026-09-24`.
Текущий запрос — источник, результаты аудита — события. Существующий terminal_runner
исполняет проверку текущего репозитория и сохраняет квитанцию. Отдельный настоящий
MCP-процесс читает уже обновлённую память. Контрольный vault хранится за пределами
репозитория. Протокол исполнения: `CURRENT_CHAT_AUDIT_RECEIPT_2026-09-24.json`.
Это ручное подключение средствами данной сессии; постоянная служба в браузерном
ChatGPT и установка на пользовательском компьютере не заявляются.

## Следующий проверяемый результат

Историк должен по доступным исходникам дать корректную карту требований и пробелов,
а новая сессия — прочитать её без потери ограничений и без объявления всего проекта
готовым. Недоступность полного экспорта текущего чата и INSTA сохраняется как блокер.
Необходимы raw-source A6 и причинная проверка rollback. Нет оснований обещать ноль
ошибок, стопроцентную реализацию планов или полное отсутствие потери контекста.

# Project History Agent v0.6 Host Adapters Implementation Plan

> **For agentic workers:** execute task-by-task with tests before implementation changes.

**Goal:** Add real read-only history adapters for Claude Code, Codex and explicit ChatGPT exports, while transferring the current project/chat to `loftfull/FIX`.

**Architecture:** Provider adapters normalize host-native records into the existing `HistoryAdapter` session shape. The lineage resolver remains independent and evidence-gated. Repository transfer is treated as provenance: GitHub location and branch/SHA are written into project memory only after the exact remote SHA is observed.

**Tech Stack:** Python 3 standard library, JSON/JSONL, unittest, existing Project History Agent journal/auditor/doctor.

**Spec:** `docs/superpowers/specs/2026-09-16-v0.6-host-adapters-design.md`

## Global Constraints
- No adapter may mutate host-native history.
- Topic similarity alone never proves continuation.
- Do not publish real secrets to the public `loftfull/FIX` repository.
- Preserve v0.5 append-only journal semantics and deterministic replay.
- Existing v0.5 reports and migration fixtures remain valid.

## Task 1 — Claude Code JSONL adapter
Create `ClaudeCodeHistoryAdapter(root)` implementing `search()` and `inspect()`. Test representative JSONL, paths, text and file references with RED→GREEN.

## Task 2 — Codex local-session adapter
Create `CodexHistoryAdapter(root)` using rollout/session metadata, git repository/branch/SHA, message content and tool file paths. Test RED→GREEN.

## Task 3 — explicit ChatGPT export adapter
Create `ChatGPTExportHistoryAdapter(conversations_json)` that reads only an explicitly supplied export. It must not claim live account access and must not invent parent-chat relations.

## Task 4 — current-chat source package and repository provenance
Store `chat/current/USER_MESSAGES.md`, `CHAT_SOURCE.md`, hash-chained journal, snapshot and handoff. Add `loftfull/FIX` as an observed location only after GitHub confirms an exact branch checkpoint.

## Task 5 — regression and repository verification
Run full unittest suite, compileall, journal replay/auditor/doctor, secret-like scan and exact GitHub branch/tree verification. Keep A6 independent-model audit as a separate release gate.

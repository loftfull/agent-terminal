# Project History Agent v0.6 Host Adapters Design

## Goal
Make Project History Agent able to discover prior work from real host-native conversation stores without coupling the evidence core to one vendor.

## Scope
v0.6 adds three read-only adapters behind the existing `HistoryAdapter` contract:

1. `ClaudeCodeHistoryAdapter` for Claude Code JSONL session files.
2. `CodexHistoryAdapter` for Codex rollout/session JSONL files.
3. `ChatGPTExportHistoryAdapter` for a user-provided ChatGPT `conversations.json` export.

The adapters only normalize evidence candidates. They never decide lineage. `detect_chat_lineage()` remains the sole evidence gate for `new / continuation / unknown`.

## Normalized session contract
Every adapter returns at least `session_id`, `chat_id`, `title`, `provider`, `source_locator`, `text`, `repositories`, `paths`, `files`, `stable_ids`. When exposed by the source it also preserves `project_id`, `parent_session_id`, `started_at`, plans and memories.

## Parsing policy
- Read-only; never mutate host history.
- Stream JSONL line by line.
- Malformed files fail with source-qualified errors instead of silently dropping evidence.
- Unknown event/message shapes may contribute text but cannot fabricate stable IDs.
- Provider-specific parsing stays in adapters; core lineage code remains provider-neutral.
- ChatGPT export adapter accepts only an explicit export file path supplied by the host/user. It does not claim access to hidden account conversations.

## Identity ranking
Candidate discovery may rank matches, but ranking is not proof of continuation. Stable signals retain this order: explicit continuation reference / parent ID; exact repository + project/path corroboration; exact project ID plus repository/path; unique artifact/path evidence; title/topic similarity only as `possibly_related`.

## Repository transfer
`loftfull/FIX` becomes the canonical internet repository for Project History Agent. The public repository must contain project history, current-chat handoff data, tests, schemas and provenance while excluding real credentials/secrets.

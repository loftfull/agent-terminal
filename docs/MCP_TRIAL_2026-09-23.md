# Протокол локального испытания MCP

Дата: 2026-09-23. Среда: Linux, Python 3.12, mcp 2.2.0.
База: FIX `c41a158a2df088fcd35e46c88580e98d805fd589`.
Рабочая ветвь: `codex/history-mcp-foundation`.

## Результат

`python -m unittest discover -s tests -v`: **42 теста PASS**, включая 10 тестов
нового моста. Простой `unittest discover` без `-s tests` не находит тесты в этом
репозитории; такой запуск не засчитывался.

Настоящий MCP-клиент запустил дочерний сервер по stdio, обнаружил три инструмента,
получил память из существующего журнала FIX и нашёл событие v0.7. Отдельный
протокольный тест проверил очистку синтетических секретов всеми тремя инструментами.

На синтетических данных проверены: обязательные ограничения, статусы доказательств,
адресация источников при одинаковых описаниях, запрет чужого project_id,
изменённый журнал, отсутствие записи при чтении, границы запроса, повторное чтение
при смене хвоста журнала и отказ при продолжающемся изменении.

## Обнаруженные и исправленные дефекты

1. SDK 2 не принимает голый `dict` как схему структурированного ответа: используются
   `dict[str, Any]` и явный structured_output.
2. Markdown-память опускала project.constraints: добавлена обязательная секция.
3. Независимый агент-аудитор обнаружил утечку URL credentials/query и KEY=value:
   расширена очистка. При повторном аудите найдена регрессия Bearer; исправлен
   порядок очистки и добавлена протокольная проверка.
4. Аудитор обнаружил потерю связи summary → event_id/source_ids: добавлен event_index.
5. Один прежний CLI-тест зависел от внешнего CODEX_HOME: среда дочерних тестовых
   процессов теперь исключает настройки реальных хранилищ истории.

Независимый аудит выполнен отдельным агентом в той же рабочей среде. Он не является
завершением полной внешней приёмки A6 и не подтверждает анализ всех чатов.

## Границы результата

Doctor: целостность, replay, совпадение snapshot, структура, атомарная запись и
контрольная очистка PASS. Общий статус **WARN**: история host недоступна, шаблоны
hooks не установлены. Screenshot probe пропущен, визуальная проверка не проводилась.

Полнота INSTA-истории, поиск всех локальных копий на компьютере пользователя,
удалённое подключение ChatGPT и ежедневная автономная работа **не испытаны**.
Очистка распознаёт известные форматы; это не гарантия удаления любых секретов.
Hash-chain показывает целостность записей, а не истинность или авторство утверждений.

# Сообщения пользователя и избранное

Вкладка «Сообщения»: зарегистрированные message_record с author=user, полный текст
после redaction, исходный проект и дата (либо неизвестна). Поиск по тексту/проекту,
копирование, добавление/удаление избранного. Текст показывается как текст, HTML не
исполняется; переносы и повторные пробелы сохраняются. При Clipboard API отказе
полный текст выделяется для ручного копирования.

«Избранное»: сообщения из разных проектов на одном browser origin. Хранилище
localStorage отдельно от проектного журнала; пользователь явно выбирает сохранение.
Нет облачной синхронизации. При запрете/переполнении хранения — явное предупреждение
о сохранении только в текущей вкладке. Экспорт/импорт JSON переносит выбранные тексты
между проектами, адресами панели и устройствами. Экспорт содержит приватный текст;
не отправляйте его в публичные репозитории. Ничего не отправляется другим моделям.

Лимиты:200сообщений,2млнсимволов суммарного JSON; текст одной карточки до500тыссимволов
для сохранения в избранное. Просмотр не обрезает сохранённые сообщения. Импорт
проверяет схему/размер/поля и объединяет без дублей; разные project/session/message
revision/text сохраняются отдельно. Некорректный импорт не заменяет прежнее избранное.

Предпросмотр FIX_Message_Library.html построен приватно из ранее сохранённых28DOM
сообщений текущего чата,15из них пользовательские. Это историческая выборка, не
непрерывное подключение и не вся история аккаунта. Private preview вне publicGit.
Модульные JSпроверки PASS;4Python dashboard/HTTP/security checksPASS.

Браузерное испытание настоящего HTML preview:15пользовательских карточек из
сохранённой выборки, добавление одной в избранное и её просмотр подтверждены.
localStorage сообщил успешную запись. Прямой Clipboard API запрещён sandbox
предпросмотра; fallback выделил весь текст. Ctrl/Cmd+C фактически скопировал235
символов; сравнение содержимого буфера с textarea.value дало true. Автоматическое
копирование одним кликом в этой sandbox не подтверждено. UI import/export диалоги
не испытаны end-to-end; сериализация/валидация проверены JS-тестами.

# Claude Code project instruction

Read and follow `PROJECT_HISTORY_AGENT.md` before modifying this repository.
Use `PROJECT_MEMORY.md` as the quick handoff and `PROJECT_HISTORY.events.jsonl` as the immutable historical evidence stream.
Never infer a continuation from semantic similarity alone.

## Долгие задачи и визуальный контроль

Работа ведётся для владельца нескольких проектов: ему нужны сохранённая история,
понятные остановки и проверяемый результат при смене модели.
Для длительной задачи прочитай её контракт, `TASKS.md` и источники критериев.
Если следующий шаг уже разрешён и не требует решения пользователя, выполни его;
сообщай краткий статус вместе с действием. Непреодолимый блокер опиши конкретно.
Сохраняй границы разрешённого доступа: исходники и секреты нельзя публиковать
из-за автоматического продолжения. Уже выданные разрешения учитывай без повторного запроса.
Фиксируй результаты проверок со ссылками на доказательства. Сообщение об успехе
остаётся reported, пока его не подтвердит соответствующая проверка.
В итоговом отчёте сначала укажи, что ждёт пользователя, затем изменённое и найденное.
Задачи отмечай по фактическому результату; новые факты могут пересмотреть прошлое
решение с сохранением прежней версии. Никакого бесконечного автоматического «продолжай».
